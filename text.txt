13.1 — Understand the testing layers

Unit tests
Test one function or component in isolation—for example, a task validation helper.




Integration tests
Test whether routes, middleware, controllers, and services work together, often with controlled database dependencies.




End-to-end tests
Test the running system through its actual entry point, including NGINX and the API containers.
